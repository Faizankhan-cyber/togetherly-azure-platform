# Platform Architecture Overview

**Status:** Roadmap-level overview. V1 detailed design is proposed, not deployed.

This document will describe how the platform evolves from V1 through V5. Keep version-specific details in the matching architecture diagram and version plan.

- V1: initial Azure hosting, networking, Nginx, and proposed Azure Functions integration.
- V2: identity, secrets, data governance, and Bicep.
- V3: hardening, monitoring, operations, backup, and patching.
- V4: security detection, Sentinel, KQL, and investigations.
- V5: enterprise architecture, availability, and disaster recovery.

Do not mark a component deployed until implementation and verification evidence exists. See [V1 architecture](v1-architecture.md) and [version plans](../versions/).
