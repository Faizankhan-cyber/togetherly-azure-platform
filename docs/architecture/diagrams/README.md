# Architecture Diagrams

Store editable Mermaid source diagrams for each platform version here. The accompanying Markdown architecture documents should explain components, request flows, trust boundaries, assumptions, and open decisions.

- `v1-architecture.mmd`: source for the current proposed V1 logical diagram.
- Add V2–V5 diagrams when those architectures are designed.

A diagram represents a proposal until the corresponding deployment is implemented and verified.
