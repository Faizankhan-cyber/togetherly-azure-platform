**Release type:** Initial project release  
**Release tag:** `v1.0.0`  
**Recommended tag target:** `65766d33e4cdd9337d7a397d7f96ccd2dc9192b7`  
**Release status:** Git tag `v1.0.0` and published GitHub release are live.

## Overview

V1 establishes the initial Azure hosting environment for the Togetherly Workforce application. It documents a VM-based deployment with Azure networking, Nginx, HTTPS and a Node.js Express API integrated with TinyFish and Supabase.

## Included

- Azure Resource Group, Virtual Network, application subnet and Network Security Group.
- Ubuntu 24.04 Linux VM deployed in Central India.
- Nginx serving the React/Vite frontend over HTTPS.
- HTTP-to-HTTPS redirect.
- Node.js Express TinyFish API managed by systemd and bound to `127.0.0.1:3001`.
- Nginx reverse proxy for `/api/tinyfish/*`.
- Integration with external Supabase and TinyFish services.
- Verification of Nginx, API service, HTTPS, unauthenticated request rejection and authenticated Search, Fetch and Agent workflows.
- Twelve sanitised implementation screenshots under `evidence/v1/`.

## Architecture notes

- The API runs on the VM as a Node.js Express service behind Nginx.
- Azure Functions was considered during planning but was not deployed.
- The Togetherly Workforce application source is maintained in its separate repository.
- V1 infrastructure was configured manually through the Azure Portal.

## Operational and security notes

- The VM was user-confirmed stopped and deallocated on 9 November 2026.
- The application is not expected to be reachable while the VM remains deallocated.
- Final live resource inventory, dependency review and resource cleanup remain pending.
- The managed disk and public IP may continue to incur charges. Check Azure Cost Management for current subscription-specific costs.
- This is a learning-project release, not a formal security audit or penetration-test report.
