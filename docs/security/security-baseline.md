# Security Baseline

**Status:** Initial guidance; controls must be validated against each version.

- Apply least privilege to Azure identities and application permissions.
- Restrict inbound network access to documented requirements.
- Keep API keys and credentials server-side and out of Git.
- Use HTTPS for public application traffic and service-to-service calls.
- Preserve application authentication, employee status, and role checks.
- Review logs and screenshots for secrets and personal information before committing.
- Record threat assumptions, residual risks, and test evidence.
- Do not modify production Supabase data or authentication settings without separate approval.
