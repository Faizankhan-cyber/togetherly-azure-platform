## Actual deployed architecture

The Togetherly Workforce frontend and TinyFish API run on one Azure Linux VM. Azure Functions was considered during planning but was not deployed. The working API is a Node.js Express service managed by systemd.

## Implementation and security notes

- The Togetherly Workforce source remains in its separate repository; only the production build is deployed on the VM.
- Nginx serves the frontend and proxies `/api/tinyfish/*` to `http://127.0.0.1:3001`.
- The API binds to loopback. Do not expose port 3001 through the NSG.
- Server-side environment values are stored in a permission-restricted `.env` file on the VM and excluded from Git.
- Supabase remains external. No production database, policy or authentication changes were made for this deployment.
- Azure Functions, its storage account and Key Vault were not deployed.
- Keep `TINYFISH_API_KEY` server-side only.
